# Support

Thanks for using **Magic PDF**! Please pick the right channel so we can help you faster.

## 💬 Questions & usage help

For "how do I…", configuration help, or general discussion, use one of these (no GitHub issue needed):

- **[GitHub Discussions](https://github.com/ELS4NTA/vscode-magic-pdf/discussions)** — ask questions, share setups, or propose ideas.
- **[Marketplace Q&A](https://marketplace.visualstudio.com/items?itemName=ELS4NTA.vscode-magic-pdf&ssr=false#qna)** — ask directly on the extension's Marketplace page.

## 🐞 Bugs & feature requests

If you've found a reproducible bug or want to request a feature, open an issue with the right template:

- **[Report a bug](https://github.com/ELS4NTA/vscode-magic-pdf/issues/new?template=bug_report.yml)**
- **[Request a feature](https://github.com/ELS4NTA/vscode-magic-pdf/issues/new?template=feature_request.yml)**

Before opening one, please search [existing issues](https://github.com/ELS4NTA/vscode-magic-pdf/issues?q=is%3Aissue) to avoid duplicates.

## 🔒 Security

Please **do not** report security vulnerabilities through public issues or discussions. See our [Security Policy](SECURITY.md) instead.
